시연 기준 거점: 현대자동차 양재 본사 충전소 (서울특별시 서초구 헌릉로 12) 및 주변 실제 상권 기반

🏆 기존 플레오스 공모전·해커톤 수상작(테일싱크·창밖동화·차마고치 등) 벤치마킹 반영 포인트

  • 시간 동기화(Time-Sync) 알고리즘: 사내 해커톤 대상작 '테일싱크(TaleSync)'가 목적지 도착 잔여 시간에 맞춰 스토리를 완결 지은 것처럼, EV MOMENT는 충전 완료 잔여 시간에 맞춰 외부 활동(이동+체류+복귀 여유)이 정확히 끝나도록 설계해 스마트폰 맛집 앱과 확실히 차별화했습니다.
  • 명확한 타깃 유저스토리(Persona): 고객 공모전 대상작 '창밖동화'의 핵심 호평 요인이었던 구체적 타깃팅을 반영해, 동승 상황(나 혼자 / 아이 동반 / 반려동물 / 비즈니스)별 보행 속도 가중치와 추천 코스가 즉시 전환되도록 구성했습니다.
  • 유기적인 차량 맥락 결합: 심사위원 핵심 기준인 "왜 스마트폰이 아니라 차량용 앱이어야 하는가?"에 답하기 위해 기어 상태(P단 충전 진입), 잔여 충전 시간, 위치 반경, 복귀 전 실내 공조 프리컨디셔닝 시나리오를 하나의 흐름으로 묶었습니다.

★ 화면 설계 방향 및 브라우저 목업 안내

  • 시스템 레이아웃 참조: Pleos Connect 공개 문서의 화면 구성 요소(상단 Status Bar, 좌측 Driving View, 우측 Application Window, 하단 GNB) 배치를 참조해 한눈에 들어오는 카드형 레이아웃으로 설계했습니다.
  • 주/야간 테마 지원: 주간(Light)/야간(Dark) 테마 전환을 지원하며, 실제 앱 출품 시 Pleos Connect Emulator 상에서 최종 시인성을 검증합니다.
  • 브라우저 시연 목업 구분: 본 HTML 파일은 기획서 이해를 돕기 위한 웹 브라우저 목업입니다. 본선 제출 및 실제 Pleos 앱 구동 검증은 Android Studio 프로젝트(APK)와 Pleos Connect Emulator 환경에서 별도로 진행합니다.

1. 개발 배경

전기차 이용자는 충전 과정에서 일정한 대기 시간을 경험합니다. 기존 충전 관련 서비스는 충전소 탐색, 충전 상태 조회 및 결제 등에 집중되어 있습니다. EV MOMENT는 충전 중 발생하는 시간을 단순한 대기 시간이 아닌 활용 가능한 생활 시간으로 전환하고자 기획한 차량용 애플리케이션입니다.

2. 서비스 개요

EV MOMENT는 차량의 충전 정보와 위치 데이터를 기반으로 주변 생활시설을 탐색하고, 이용자가 충전 완료 전에 차량으로 돌아올 수 있도록 맞춤형 활동을 추천하는 서비스입니다.

3. 주요 기능 및 우선순위

  • [우선순위 1] 충전 상태 확인: 배터리 잔량(SoC)·충전 상태 및 예상 잔여 시간 확인 (수동 입력·시뮬레이션 지원)
  • [우선순위 2] 주변 활동 추천: 현대차 본사 충전소 주변 실제 카페·식당·공원·마트 탐색
  • [우선순위 3 · 핵심 차별화] 시간 맞춤 추천: 왕복 도보·체류·복귀 여유시간(Buffer) 통합 계산
  • [우선순위 4 · 핵심 차별화] 충전 일정 동기화: 충전 잔여 시간 변동 시 추천 및 체류 방식 실시간 재계산
  • [우선순위 5] 개인화: 선호 활동과 동승 상황(나 혼자, 아이 동반, 반려동물, 비즈니스) 반영

4. 기술 구현 계획 (42dot OT 기준 Pleos SDK & Virtual Console 검증 구조)

• 개발 환경 및 권한 선언 (연동 계획): Android WebView 기반 프로젝트 소스를 제공하지만 Pleos Emulator 빌드·SDK 실호출은 미검증입니다. AndroidManifest의 선언만으로 Vehicle/NaviHelper/FusedLocation SDK가 실제 연결되지는 않으며, 공식 문서 기준 의존성·권한·호출 구현이 추가로 필요합니다.
• Virtual Console 연동 계획: 앱에는 JavaScript로 시연용 SoC·충전 시간 값을 반영하는 브리지 연결 지점이 있습니다. Virtual Console에서 실제 이벤트를 받아오는 기능은 아직 없습니다. 현재는 수동 시간 조정 및 시뮬레이션으로 재계산을 확인합니다.
• 외부 API 및 안내 기능: Overpass 장소 조회 요청 코드와 브라우저 알림·Android 기본 TTS 연결 지점이 있습니다. 실제 NaviHelper 경유지 등록 및 Pleos 전용 TTS SDK 연동은 아직 구현하지 않았습니다.

5. 공식 OT 발표 4대 필수 심사 기준 부합성 (차량 특화성 · 창의성 · 기술 활용성 · 사업성)

  • ① 차량 특화성 (모바일과 다른 차량 고유 가치): 스마트폰 맛집 앱과 달리 '차량 P단 정차·충전 진입 맥락 + 배터리 가용 시간 + 동승자 특성 + 복귀 전 공조 예약'을 결합해 차량 환경에서만 성립하는 시간 예산(Time-Budget) 경험을 제공합니다.
  • ② 창의성 (명확한 문제 정의와 해법): 전기차 차주의 가장 큰 페인 포인트인 "충전 중 어디까지 다녀와야 제시간에 복귀할 수 있는가?"를 왕복 도보·체류·안전 버퍼 통합 수식과 충전 시간 변동 시 원터치 재조정으로 명확히 해결했습니다.
  • ③ 기술 활용성 (핵심 기능 중심의 SDK 선택과 집중): 시간 예산 엔진은 웹 프로토타입으로 구현했습니다. 실제 차량 연동을 위해 Vehicle SDK(배터리·기어), FusedLocation(차량 위치), NaviHelper(경유지), 음성 안내 SDK 연동을 후속 개발 범위로 설계했습니다.
  • ④ 사업성 (타깃 고객 및 지속 수익 모델): 명확한 전기차 충전 대기 고객층을 타깃으로 하며, 향후 충전소(E-pit 등) 주변 로컬 상권의 '충전 시간 맞춤 픽업·타임 쿠폰·웨이팅 연동' 제휴 플랫폼으로 확장 가능성이 높습니다.
